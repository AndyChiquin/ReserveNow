# 📅 Schedules Microservice

This microservice manages restaurant schedules, allowing the creation, retrieval, and association of schedules with special days. It ensures that schedules are linked to existing special days before assigning them.

## 🚀 Features
- Create schedules with validation against existing special days.
- Retrieve schedules data.
- Built with Flask and SQLAlchemy.
- Uses PostgreSQL as the database.

## 🛠️ Technologies
- **Flask** (Python framework)
- **Flask-SQLAlchemy** (ORM for database management)
- **PostgreSQL** (Relational database)
- **Docker** (Containerization)
- **AWS EC2** (Cloud hosting)
