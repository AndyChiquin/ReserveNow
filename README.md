# 🍽️ ReserveNow - Frontend

**ReserveNow** is a restaurant reservation platform, allowing users to browse restaurants, view their profiles and make reservations easily. This repository contains the **frontend** of the system, developed with **Vue.js** and **Vite**.

---

## 🚀 Technologies Used.

- **Vue.js** - JavaScript framework for building web interfaces.
- **Vite** - Tool for fast and efficient development.
- Vue Router** - For navigation between views.
- CSS3** - Frontend styling.
- ES6+** - Modern JavaScript.
