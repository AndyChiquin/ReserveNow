# 🍽️ Menu Service

This microservice is part of the **ReserveNow** system and is responsible for managing restaurant menus. It allows users to **create, read, update, and delete** menu items while ensuring that each menu entry is linked to a valid restaurant.

## 🚀 Features
- **Create** a new menu item.
- **Read** menu items by ID or retrieve all menus.
- **Update** menu items while validating restaurant existence.
- **Delete** a menu item.

## 🛠️ Technologies Used
- **Python** (Flask)
- **MySQL** (AWS RDS)
- **SQLAlchemy** (ORM)
- **Docker & Docker Compose**
- **GitHub Actions** (for CI/CD)
