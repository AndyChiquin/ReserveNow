# 🪑 Table Management Microservice

This microservice handles **table management** for a **restaurant reservation system**. It allows users to perform **CRUD operations** on tables, ensuring availability and status updates in a **MySQL database**.

## 🚀 Features
- ✅ **Create** a new table (`POST /tables`)
- ✅ **Retrieve** all tables (`GET /tables`)
- ✅ **Retrieve** a table by ID (`GET /tables/{id}`)
- ✅ **Update** table status (`PUT /tables/{id}`)
- ✅ **Delete** a table (`DELETE /tables/{id}`)

## 🛠️ Technologies Used
- **Node.js** (Express.js for API development)
- **MySQL** (Relational database)
- **Sequelize** (ORM for database interaction)
- **Docker** (for containerized deployment)
- **AWS RDS** (for database hosting)
- **Postman** (for API testing)
